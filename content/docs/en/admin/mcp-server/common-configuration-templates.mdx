These examples cover remote HTTP servers that use the gateway and `stdio` servers that run locally.

## Managed HTTP: API key in a request header

Click **Add Manually** and use this example in the JSON configuration. Replace the URL, header, and value with the settings from your provider. After you save, the gateway stores the header credential. Callers use the proxy URL.

```json
{
  "name": "Team Search",
  "type": "streamableHttp",
  "baseUrl": "https://mcp.example.com/mcp",
  "headers": { "Authorization": "Bearer REPLACE_WITH_API_KEY" }
}
```

## Managed HTTP: Personal OAuth

1. In the form, select `streamableHttp` and enter the provider's MCP URL.
2. If the provider supports DCR, select **OAuth 2.1 (Dynamic Registration / DCR)**. If the provider requires a registered app, select **OAuth 2.1 (Pre-registered App)**, register the redirect URI from the form, and enter the app credentials.
3. Set **Credential scope** to **Personal account** and save. Members open `/connections`, find the server on the MCP Servers page, and select **Connect**.

For OAuth, do not enter an access token in the request headers.

## 🌐 Playwright (Web Automation)

Enables browsing webpages, taking screenshots, and scraping data.

* **Dependencies**: Node.js
* **Use cases**: Web search assistants, news summary assistants.

```json
{
  "name": "Playwright",
  "type": "stdio",
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-playwright"
  ]
}
```

## 📂 Filesystem (Local Filesystem)

Enables reading and writing to specific server directories.

* **Dependencies**: Node.js
* **Use cases**: Code audit assistants, log analysis assistants.

<Callout type="error">
**Security warning:** Always specify a **safe directory** in `args` (e.g., `/Users/admin/desktop`). Never grant root `/` access to avoid accidental deletion.
</Callout>

```json
{
  "name": "Filesystem",
  "type": "stdio",
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-filesystem",
    "/Users/username/desktop/allowed-folder"
  ]
}
```

## 📡 Fetch (HTTP Requests)

Enables HTTP requests.

* **Dependencies**: Python (uv) or Node.js
* **Use cases**: API testing, simple data scraping.

```json
{
  "name": "Fetch",
  "type": "stdio",
  "command": "uv",
  "args": [
    "x",
    "mcp-server-fetch"
  ]
}
```
