**ナビゲーション：** サイドバー → AI 社員 → 社員をクリック → **役割**、**拡張機能**、または **シークレット** タブ

社員の詳細にある **役割**、**拡張機能**、**シークレット** の 3 つのタブで、社員の働き方が決まります。これらの設定を変更できるのは、**管理者**と所属グループの**グループ管理者**だけです。一般メンバーは閲覧のみ可能です。

## 役割

**役割** タブには、社員の業務指示、使用するモデル、性格と表現方法が表示されます。

<img src="/assets/images/ja/admin/ai-employees-duties_ja.webp" alt="役割タブ" />

**業務指示**は、社員が作業のたびに読み込む指示の全文です。社員の作成時に、システムが職務、担当業務、作業ルールから業務指示を生成します。

### 担当業務と機能の変更

1. **役割** タブで **業務と能力を編集** をクリックします。
2. **業務指示**、**性格と表現方法**、またはモデルを変更します。
3. **保存** をクリックします。

<img src="/assets/images/ja/admin/ai-employees-edit-duties_ja.webp" alt="担当業務と機能の編集" />

<Callout type="info">
社員の名前や職務の概要を変更しても、業務指示は書き換わりません。社員の働き方を変えるには、業務指示を直接変更してください。
</Callout>

保存後に設定が反映されるタイミング：

## 拡張機能

**拡張機能** タブでは、社員のスキルと MCP サーバーを管理します。

<img src="/assets/images/ja/admin/ai-employees-extensions_ja.webp" alt="拡張機能タブ" />

### スキル

スキルは、特定の種類の業務を行うための指針とスクリプトを社員に提供します。スキルは[エージェントスキル](/ja/docs/admin/agent-skills)のライブラリから取得します。

* **スキルの追加：** **ライブラリから追加** をクリックし、グループで利用可能なスキルを選択します。
* **有効化・無効化：** スキルの右側のスイッチを使います。
* **削除：** 削除アイコンをクリックします。ライブラリ内のスキルには影響しません。
* **更新：** ライブラリのスキルに新しいバージョンがあると、スキルの横に **更新** ボタンが表示されます。クリックすると、社員が新しいバージョンを使用します。

<Callout type="info">
スキルは追加後、その社員が個別に管理します。ライブラリでスキルが更新されても、社員のスキルは自動的には上書きされません。
</Callout>

### MCP サーバー

MCP サーバーは、チケットシステムの照会など、外部ツールを社員に提供します。MCP サーバーは [MCP サーバー](/ja/docs/admin/mcp-server)のライブラリから取得します。

* **ライブラリから追加** をクリックし、グループで利用可能な MCP サーバーを選択します。
* MCP サーバーの変更は、社員の次回の実行から反映されます。
* ページには MCP サーバーの認証情報は表示されません。

<Callout type="warn">
**標準従業員が使用できるのは、HTTP タイプ（streamable HTTP）の MCP サーバーだけです。** 標準従業員に使わせる MCP サーバーは、ライブラリで HTTP タイプとして設定してください。
</Callout>

## シークレット

シークレットは、社員のツールに渡す認証情報です。例えば、業務システムの API トークンです。シークレットは環境変数として社員に渡されます。

<img src="/assets/images/ja/admin/ai-employees-secrets_ja.webp" alt="シークレットタブ" />

### シークレットの追加・更新

1. **シークレット** タブで **シークレットを追加・更新** をクリックします。
2. **変数名** に環境変数名を入力します。例：`TICKET_API_TOKEN`。
3. **シークレットの値** にシークレットを入力します。
4. **保存** をクリックします。

<img src="/assets/images/ja/admin/ai-employees-secret-add_ja.webp" alt="シークレットの追加・更新" />

* 保存後、ページにはシークレットの変数名のみが表示され、元の値は表示されません。
* 同じ変数名がすでにある場合は、新しい値が古い値を置き換えます。
* シークレットは、その社員またはアシスタントだけのものです。社員とそのアシスタントは、シークレットを個別に管理します。

### シークレットの削除

シークレットの右側にある削除アイコンをクリックします。標準従業員の場合、実行中のタスクは、次にシークレットを検証するときに中止されます。削除は他の社員やアシスタントには影響しません。

<Callout type="info">
プラットフォームとチャネルの認証情報はシステムが管理しており、**シークレット** タブには表示されません。
</Callout>
