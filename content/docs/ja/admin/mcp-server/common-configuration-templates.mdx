ゲートウェイ管理のリモート HTTP サーバーと、ローカルで実行する `stdio` サーバーの設定例を紹介します。

## ゲートウェイ管理の HTTP：リクエストヘッダーの API キー

**Add Manually** をクリックし、JSON 設定で次の例を使います。URL、ヘッダー、値は提供元が指定する内容に置き換えます。保存後、リクエストヘッダーの資格情報はゲートウェイが管理し、呼び出し元はプロキシ URL を使います。

```json
{
  "name": "Team Search",
  "type": "streamableHttp",
  "baseUrl": "https://mcp.example.com/mcp",
  "headers": { "Authorization": "Bearer REPLACE_WITH_API_KEY" }
}
```

## ゲートウェイ管理の HTTP：個人 OAuth

1. フォームで `streamableHttp` を選び、提供元の MCP URL を入力します。
2. 提供元が DCR に対応している場合は **OAuth 2.1 (Dynamic Registration / DCR)** を選びます。事前登録が必要な場合は **OAuth 2.1 (Pre-registered App)** を選びます。フォームのリダイレクト URI を提供元に登録し、アプリの資格情報を入力します。
3. **資格情報スコープ** を **Personal account** に設定して保存します。メンバーは `/connections` を開き、移動先の MCP サーバーページで対象の **Connect** をクリックします。

OAuth の場合、リクエストヘッダーにアクセストークンを入力する必要はありません。

## 🌐 Playwright（Web 自動化）

Web の閲覧、スクリーンショット、データ取得が可能になります。

* **依存**：Node.js
* **用途**：Web 検索アシスタント、ニュース要約。

```json
{
  "name": "Playwright",
  "type": "stdio",
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-playwright"
  ]
}
```

## 📂 Filesystem（ローカルファイル）

特定ディレクトリの読み書きが可能になります。

* **依存**：Node.js
* **用途**：コード監査、ログ分析。

<Callout type="error">
**セキュリティ警告:** `args` には必ず **安全なディレクトリ** を指定してください（例：`/Users/admin/desktop`）。ルート `/` の付与は禁止です。
</Callout>

```json
{
  "name": "Filesystem",
  "type": "stdio",
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-filesystem",
    "/Users/username/desktop/allowed-folder"
  ]
}
```

## 📡 Fetch（HTTP リクエスト）

HTTP リクエストの送信が可能になります。

* **依存**：Python（uv）または Node.js
* **用途**：API テスト、簡易データ取得。

```json
{
  "name": "Fetch",
  "type": "stdio",
  "command": "uv",
  "args": [
    "x",
    "mcp-server-fetch"
  ]
}
```
