MCP サーバーを設定すると、アシスタントに以下の能力を付与できます：

* **Web アクセス**：リアルタイムで検索。
* **ファイル操作**：ローカルのコードやログの読み書き。
* **システム連携**：DB、API、社内システムとの接続。

<Callout type="info">
管理者は同じ MCP サーバーを複数のアシスタントに割り当てられます。共有資格情報は管理者が設定します。個人 OAuth 接続はメンバーごとに認可が必要です。
</Callout>

## ゲートウェイ管理の HTTP MCP

リモート HTTP MCP（`streamableHttp` または `sse`）には、プラットフォームの `/v1/mcps/:key/mcp` 経由でアクセスします。接続先の資格情報はプラットフォームの Vault が暗号化して保存します。デスクトップクライアントと AI 従業員のコンテナはプラットフォームの資格情報でゲートウェイに接続し、接続先のシークレットや OAuth トークンを受け取りません。

<Callout type="warn">
`stdio` サーバーは、デスクトップまたは対応する AI 従業員のコンテナ内で実行されます。`env` の値は実行環境に配布されるため、機密性の高い資格情報を入れないでください。リスクの高い外部連携では、ゲートウェイ管理の HTTP MCP を優先してください。
</Callout>
