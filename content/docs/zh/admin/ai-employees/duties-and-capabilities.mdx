员工详情的 **职责**、**扩展** 和 **密钥** 三个标签页决定员工怎样工作。只有**管理员**和本组的**组管理员**可以修改这些配置。普通成员只能查看。

## 职责

**职责** 标签页显示员工的工作指令、使用的模型和性格与表达方式。

<img src="/assets/images/zh/admin/ai-employees-duties_zh.webp" alt="职责标签页" />

**工作指令**是员工每次工作时读取的完整指令。创建员工时，系统根据岗位、职责和工作规则生成工作指令。

### 修改职责与能力

1. 在 **职责** 标签页，点击 **修改职责与能力**。
2. 修改 **工作指令**、**性格与表达方式** 或模型。
3. 点击 **保存**。

<img src="/assets/images/zh/admin/ai-employees-edit-duties_zh.webp" alt="修改职责与能力" />

<Callout type="info">
修改员工的姓名或岗位简介不会改写工作指令。要改变员工的工作方式，直接修改工作指令。
</Callout>

保存后的生效时间：

<table><thead><tr><th width="140">员工类型</th><th>生效时间</th></tr></thead><tbody><tr><td><strong>标准员工</strong></td><td>下一次运行使用新配置。正在进行的运行继续使用原来的工作指令、模型和技能。</td></tr><tr><td><strong>增强员工</strong></td><td>新的网页会话使用新配置。已有的网页会话保留原来的工作指令，模型和性格与表达方式从下一次回复开始生效。渠道中的会话可能需要先暂停员工，再恢复工作。</td></tr></tbody></table>

## 扩展

**扩展** 标签页管理员工的技能和 MCP 服务。

<img src="/assets/images/zh/admin/ai-employees-extensions_zh.webp" alt="扩展标签页" />

### 技能

技能为员工提供完成某类工作的指引和脚本。技能来自[智能体技能](/zh/docs/admin/agent-skills)资源库。

* **添加技能：** 点击 **从资源库添加**，选择本组可用的技能。
* **启用或停用：** 使用技能右侧的开关。
* **移除：** 点击删除图标。资源库中的技能不受影响。
* **更新：** 资源库中的技能有新版本时，技能旁边显示 **更新** 按钮。点击后员工使用新版本。

<Callout type="info">
技能添加后由这位员工独立管理。资源库更新技能时，不会自动覆盖员工的技能。
</Callout>

### MCP 服务

MCP 服务为员工提供外部工具，例如查询工单系统。MCP 服务来自 [MCP 服务器](/zh/docs/admin/mcp-server)资源库。

* 点击 **从资源库添加**，选择本组可用的 MCP 服务。
* MCP 服务的修改从员工的下一次运行开始生效。
* 页面不显示 MCP 服务的凭据。

<Callout type="warn">
**标准员工只支持 HTTP 类型（streamable HTTP）的 MCP 服务。** 需要给标准员工使用的 MCP 服务，在资源库中按 HTTP 类型配置。
</Callout>

## 密钥

密钥是提供给员工工具使用的凭据，例如业务系统的 API 令牌。密钥以环境变量的形式提供给员工。

<img src="/assets/images/zh/admin/ai-employees-secrets_zh.webp" alt="密钥标签页" />

### 添加或更新密钥

1. 在 **密钥** 标签页，点击 **添加或更新密钥**。
2. 在 **变量名** 中填写环境变量名，例如 `TICKET_API_TOKEN`。
3. 在 **密钥值** 中填写密钥。
4. 点击 **保存**。

<img src="/assets/images/zh/admin/ai-employees-secret-add_zh.webp" alt="添加或更新密钥" />

* 保存后，页面只显示密钥的变量名，不显示原值。
* 变量名已存在时，新值替换旧值。
* 密钥只属于当前员工或助理。员工和它的助理分别管理密钥。

### 删除密钥

点击密钥右侧的删除图标。对于标准员工，正在运行的任务在下一次校验密钥时中止。删除不影响其他员工和助理。

<Callout type="info">
平台和渠道的凭据由系统管理，不显示在 **密钥** 标签页中。
</Callout>
